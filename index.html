01

Polynomial & Rational Inequalities

The method

  1. Get everything on one side, 0 on the other.
  2. Factor completely (for a rational expression, factor numerator and denominator separately — never multiply the denominator across the inequality).
  3. Find boundary points: zeros of the numerator (included, unless the inequality is strict at a hole) and zeros of the denominator (always excluded — undefined).
  4. Plot boundary points on a number line and test a value in each interval to get the sign of the whole expression there.
  5. A factor raised to an even power never changes sign — it touches zero but the sign chart stays the same on both sides.
  6. Read off the intervals that satisfy the inequality, using [ ] for included boundary points and ( ) for excluded ones.

Key facts & common mistakes

  • Strict vs. non-strict: for < or > no boundary point is ever included. For ≤ or ≥, include numerator zeros (they make the expression 0) but never denominator zeros.
  • Odd multiplicity (power 1, 3, 5…) → the sign flips at that boundary point. Even multiplicity (power 2, 4…) → the sign stays the same.
  • n boundary points always cut the number line into n + 1 intervals — count them as a check on your sign chart.
  • Never multiply both sides by a variable expression: its sign is unknown, so the inequality might need to flip. Move everything to one side and combine into a single fraction instead.
  • Isolated solutions like {−5} only appear with ≥ 0 or ≤ 0 when an even-multiplicity zero sits between two intervals that do not qualify.
  • Check yourself: plug one number from your answer (and one from outside it) into the original inequality.

PROBLEM 1(a) — cubic, already factored

(x + 3)(2 − x)(5 + x)² ≥ 0

▶ Show solution

Boundary points: x = −5, −3, 2. The factor (5+x)² is squared, so the chart doesn't switch sign across x = −5 — it just touches zero there.

Signs: (−∞,−5) neg   (−5,−3) neg   (−3,2) pos   (2,∞) neg

Since the inequality is ≥ 0, we want the positive interval plus every zero (they make the expression exactly 0, which satisfies ≥):

{−5} ∪ [−3, 2]

Note x = −5 is included as an isolated point (a "touch" zero), not a full interval.

PROBLEM 1(b) — rational inequality

(x + 1)² / [(x + 7)(x − 3)] ≤ 0

▶ Show solution

Boundary points: x = −7, −1, 3. Since x=−7 and x=3 come from the denominator, they're always excluded (undefined there). x=−1 comes from a squared numerator factor — the chart doesn't change sign across it.

Signs: (−∞,−7) pos   (−7,−1) neg   (−1,3) neg   (3,∞) pos

We want ≤ 0: the two negative intervals, joined into one since the sign doesn't flip at the touch point x=−1, plus that point itself (it makes the expression 0):

(−7, 3)

Endpoints −7 and 3 stay open (parentheses) forever — a denominator zero is never included.

PROBLEM 1(c) — must factor first, then 2 & 6: same idea applied to non-factored polynomials

8x³ − 9 < 18x − 4x²  →  8x³ + 4x² − 18x − 9 < 0  →  group and factor

▶ Show solution

Grouping: 4x²(2x+1) − 9(2x+1) < 0 → (2x+1)(4x²−9) < 0 → (2x+3)(2x−3)(2x+1) < 0.

Boundary points: x = −3/2, −1/2, 3/2, all simple (odd) factors, so the sign flips at every one.

Signs: (−∞,−3/2) neg   (−3/2,−1/2) pos   (−1/2,3/2) neg   (3/2,∞) pos

We want strictly < 0 (endpoints excluded, since the original is strict):

(−∞, −3/2) ∪ (−1/2, 3/2)

02

Finding Real Zeros

The method

  • If the polynomial factors directly (grouping, difference of squares, quadratic in disguise), do that first — it's faster than the Rational Root Theorem.
  • Otherwise, test possible rational zeros (± factors of the constant term over factors of the leading coefficient) using synthetic division. A remainder of 0 confirms a zero and drops the degree by one.
  • Once you're down to a quadratic, finish with factoring or the quadratic formula.
  • An irreducible quadratic factor (negative discriminant) contributes no real zeros — leave it factored, or use it later for complex zeros.

Key facts & shortcuts

  • Rational Root Theorem: any rational zero has the form ±p/q, where p divides the constant term and q divides the leading coefficient. Example: 2x³ − 11x² + 10x + 8 → p ∈ {1, 2, 4, 8}, q ∈ {1, 2} → candidates ±1, ±2, ±4, ±8, ±½.
  • Quick tests: if the coefficients add up to 0, then x = 1 is a zero (because f(1) = sum of coefficients). If the alternating sum is 0, x = −1 is a zero.
  • Fundamental Theorem of Algebra: a degree-n polynomial has exactly n zeros counting multiplicity and complex zeros; at most n of them are real.
  • Descartes' Rule of Signs: the number of positive real zeros equals the number of sign changes in f(x), or that number minus an even number. For negative zeros, count sign changes in f(−x).
  • Test the easy candidates first (±1, ±2) — most exam problems are built to have small integer zeros.

PROBLEM 3 — factors directly as a quadratic in x²

g(x) = 4x⁴ + 15x² − 4

▶ Show solution

Treat x² as the variable: 4u² + 15u − 4 = (4u − 1)(u + 4), so

g(x) = (4x² − 1)(x² + 4) = (2x−1)(2x+1)(x²+4)

x² + 4 has no real roots (it's always positive), so it contributes nothing to the real zeros.

Zeros: x = −1/2, x = 1/2

PROBLEM 4 — degree 4, needs two rounds of synthetic division

f(x) = x⁴ − 4x³ − 7x² + 34x − 24

▶ Show solution

Try x = 1: synthetic division with coefficients 1, −4, −7, 34, −24 gives remainder 0, quotient x³ − 3x² − 10x + 24.

Try x = 2 on that cubic: remainder 0, quotient x² − x − 12 = (x−4)(x+3).

f(x) = (x−1)(x−2)(x−4)(x+3)  ·  Zeros: 1, 2, 4, −3

Notice the same synthetic-division numbers reappear in Problem 5's setup — building the "drop a degree, repeat" reflex here pays off there too.

03

Division & the Factor Theorem

The method

  • Synthetic division only works when dividing by a linear factor (x − c). Use c, not −c, in the synthetic division row.
  • The bottom row gives the quotient's coefficients (one degree lower); the last number is the remainder.
  • Factor Theorem: (x − c) is a factor of f(x) exactly when f(c) = 0. You can check this by direct substitution instead of full division if you only need a yes/no answer.
  • Missing terms (no x² term, etc.) still need a placeholder 0 coefficient in the synthetic division row.

Key facts & connections

  • Remainder Theorem: when f(x) is divided by (x − c), the remainder equals f(c). So synthetic division is also a fast way to evaluate a polynomial.
  • Division statement: f(x) = (x − c)·q(x) + r, or equivalently f(x)/(x − c) = q(x) + r/(x − c). That second form is exactly how you find oblique asymptotes in Section 6.
  • The quotient always has degree one less than the dividend — a fast way to catch a missing placeholder 0.
  • To divide by something like (2x + 1), or by a quadratic, synthetic division does not apply — use long division.
  • Remainder 0 does three things at once: (x − c) is a factor, x = c is a zero, and (c, 0) is an x-intercept.

PROBLEM 5 — quotient & remainder, watch the missing x² term

(x⁴ + 4x³ + 16x − 35) ÷ (x + 5)

▶ Show solution

Dividing by x + 5 means using c = −5. Write the coefficients with a 0 placeholder for the missing x² term: 1, 4, 0, 16, −35.

Synthetic row: 1 −1 5 −9 | remainder 10

Quotient: x³ − x² + 5x − 9  ·  Remainder: 10

A nonzero remainder means x + 5 is not a factor — that's fine here, the problem only asked for quotient and remainder.

PROBLEM 6 — Factor Theorem by direct substitution

g(x) = x⁴ − x³ − 6x² + 4x + 8. Is (x+1) a factor? Is (x−2) a factor?

▶ Show solution

g(−1) = 1 + 1 − 6 − 4 + 8 = 0 → yes, x+1 is a factor.

g(2) = 16 − 8 − 24 + 8 + 8 = 0 → yes, x−2 is a factor.

No division needed for a yes/no question — plug the root straight into the function.

PROBLEM 7 — one synthetic division step gives a quadratic to finish by hand

f(x) = 2x³ − 11x² + 10x + 8  → intercepts

▶ Show solution

Trying x = 2: coefficients 2, −11, 10, 8 → row 2, −7, −4 | remainder 0, so f(x) = (x−2)(2x² − 7x − 4) = (x−2)(2x+1)(x−4).

x-intercepts: (2,0), (−1/2,0), (4,0)  ·  y-intercept: (0,8)

The y-intercept is always just f(0) — the constant term when the polynomial is expanded — no division needed for that part.

04

Complex Zeros

The method

  • Find one real zero first (Rational Root Theorem + synthetic division), which reduces the polynomial to a quadratic.
  • If that quadratic has a negative discriminant, finish it with the quadratic formula — the √(negative) becomes i·√(positive).
  • Complex zeros always come in conjugate pairs a ± bi for polynomials with real coefficients — you never get just one.
  • To write the fully factored form, each complex zero c contributes a factor (x − c), same as a real zero.

Key facts & checks

  • Non-real zeros of a real-coefficient polynomial come in pairs, so an odd-degree polynomial always has at least one real zero.
  • Sum and product check (degree 3, ax³ + bx² + cx + d): sum of zeros = −b/a, product = −d/a. For Problem 8: −2 + (−2+i) + (−2−i) = −6 ✓.
  • A conjugate pair a ± bi multiplies to the real quadratic x² − 2a·x + (a² + b²).
  • Remember i² = −1, so √(−4) = 2i. Always simplify the radical before splitting the fraction.
  • Complex zeros are not x-intercepts — they never appear on the real graph.

PROBLEM 8 — real zero first, then the quadratic formula

h(x) = x³ + 6x² + 13x + 10

▶ Show solution

Try x = −2: coefficients 1, 6, 13, 10 → row 1, 4, 5 | remainder 0, so h(x) = (x+2)(x²+4x+5).

Quadratic formula on x²+4x+5: x = (−4 ± √(16−20))/2 = (−4 ± √(−4))/2 = −2 ± i.

Zeros: x = −2, x = −2+i, x = −2−i
h(x) = (x+2)(x+2+i)(x+2−i)

The two complex zeros are conjugates of each other — that's the pattern to expect anytime the discriminant is negative.

05

Graphing Polynomials

The method

  1. Fully factor to find every real zero — this may take repeated synthetic division just like Section 2.
  2. End behavior comes from the leading term only: even degree + positive leading coefficient → both ends up; odd degree + positive → down-left, up-right (flip both rules if the leading coefficient is negative).
  3. Multiplicity at each zero controls the local shape: odd multiplicity crosses the x-axis, even multiplicity touches and bounces back.
  4. Plot the y-intercept (f(0)) and at least one extra point between zeros (evaluate f there) to fix how high or low the curve swings.
  5. Scale the axes so the extra point(s) actually fit on the grid.

End behavior & shape reference

DegreeLeading coeff.Left endRight end
EvenPositiveUp ↑Up ↑
EvenNegativeDown ↓Down ↓
OddPositiveDown ↓Up ↑
OddNegativeUp ↑Down ↓
  • A degree-n polynomial has at most n − 1 turning points.
  • Multiplicity 1: crosses like a line. Multiplicity 2: bounces like a parabola. Multiplicity 3: crosses but flattens out at the axis (like x³).
  • Between consecutive zeros the graph stays entirely above or entirely below the axis, so one test point per interval is enough to know which.
  • Polynomials are smooth and continuous: no gaps, no sharp corners, no asymptotes.

PROBLEM 9 — full sketch, degree 4

f(x) = x⁴ + 3x³ − 9x² − 23x − 12

▶ Show solution

Synthetic division at x = −1 then x = 3 reduces the quartic step by step to:

f(x) = (x+1)(x−3)(x+4)(x+1) = (x+1)²(x−3)(x+4)

x-intercepts: (−1,0) — even multiplicity, so the curve touches the axis here and turns back; (3,0) and (−4,0) — odd multiplicity, so the curve crosses.

y-intercept: f(0) = −12.

Degree 4, positive leading coefficient → both ends rise. Extra points f(−2) = −10 and f(2) = −54 confirm the curve stays below the x-axis from x=−4 to x=3 (touching at x=−1) and dips to about −55, which is why the y-axis needed to scale down to −60.

06

Rational Functions

The method

Always factor the numerator and denominator completely first, then cancel any factor common to both — that cancelled factor is a hole, not a vertical asymptote.

FeatureHow to find it
x-intercept(s)Zeros of the numerator after cancelling common factors.
y-interceptEvaluate the (simplified) function at x = 0.
Vertical asymptoteZeros of the denominator that remain after cancelling.
HoleA factor that cancels from both numerator and denominator — plug its x-value into the simplified function to get the hole's y-coordinate.
Horizontal asymptoteCompare degrees (numerator n, denominator m): n < m → y = 0. n = m → y = ratio of leading coefficients. n > m → no horizontal asymptote (see the oblique rule below).
Oblique (slant) asymptoteOnly when n = m + 1 (numerator degree is exactly one more than the denominator). Divide the numerator by the denominator; the quotient y = mx + b is the asymptote and the remainder is ignored.

Asymptote rules at a glance (degree of top = n, bottom = m)

CaseHorizontalObliqueExample
n < my = 0None1/(x−2)
n = my = a/b (leading coefficients)None(3x²+1)/(x²−4) → y = 3
n = m + 1NoneYes — quotient of the division(x²+1)/(x−1) → y = x + 1
n > m + 1NoneNone (curve follows a parabola, cubic, etc.)x³/(x−1) ~ x² + x + 1
  • Why it works: for huge |x| only the leading terms matter, so f(x) ≈ (a·xⁿ)/(b·xᵐ) = (a/b)·xⁿ⁻ᵐ. If n − m = 0 that is a constant, if n − m = 1 that is a line (oblique), if n − m > 1 it is a curve.
  • Worked oblique example: (x² + 1)/(x − 1). Synthetic division with c = 1 on 1, 0, 1 gives row 1, 1 | 2, so f(x) = x + 1 + 2/(x − 1). As |x| grows the fraction → 0, so the graph hugs y = x + 1. Vertical asymptote: x = 1.
  • A function has at most one of horizontal or oblique — never both — and at most one on each end.
  • The graph can cross a horizontal or oblique asymptote in the middle (solve f(x) = y-value to find where). It can never cross a vertical asymptote.
  • Rational functions can have any number of vertical asymptotes, but degree-based (horizontal/oblique) asymptotes are limited to one.

Vertical asymptotes, holes & behavior near them

  • Hole vs. vertical asymptote: if a factor cancels completely it is a hole. If some copies remain in the denominator (as in Problem 12), the leftover makes a vertical asymptote.
  • Behavior at a vertical asymptote: odd multiplicity of the denominator factor → the curve goes to opposite infinities on each side. Even multiplicity → the same infinity on both sides (Problem 11 at x = −1 dives to −∞ on both sides).
  • The domain is all reals except every zero of the original denominator — holes and vertical asymptotes.
  • A hole's y-value comes from the simplified function. It is drawn as an open circle.
  • Simplify only for graphing; always find the domain from the original expression.

Graphing a rational function — step by step

  1. Factor the top and bottom completely and state the domain.
  2. Cancel common factors → note each hole's x-value, then its y-value from the simplified function.
  3. Vertical asymptotes: remaining zeros of the denominator. Draw as dashed lines.
  4. Compare n and m → horizontal asymptote, oblique asymptote (divide!), or neither.
  5. Plot x-intercepts (zeros of the simplified numerator) and the y-intercept f(0).
  6. Build a sign chart using all zeros of numerator and denominator, or plot 1–2 extra points in each region between vertical asymptotes.
  7. Sketch each piece, making it approach every asymptote without crossing the vertical ones.

When does a rational graph cross its horizontal (or oblique) asymptote?

A horizontal asymptote describes what happens at the far ends (x → ±∞). It says nothing about the middle of the graph, so the curve may cross it there — even several times — before settling toward it.

  1. Method 1 — set f(x) equal to the asymptote: solve f(x) = y₀, where y₀ is the horizontal asymptote. Every solution in the domain is a crossing point (x, y₀). No solution → the graph never crosses.
  2. Method 2 — divide and look at the remainder: write f(x) = quotient + R(x)/D(x). The graph sits exactly on the asymptote only where R(x) = 0. If R is a nonzero constant, it never crosses. Works for oblique asymptotes too.
  • Example (crosses): f(x) = (2x² + x)/(x² + 1) has HA y = 2. Set 2x² + x = 2(x² + 1) → x = 2. It crosses at (2, 2). (Check: f = 2 + (x − 2)/(x² + 1), and the remainder is 0 at x = 2.)
  • Example (never crosses): Problem 12's f(x) = −(x+4)/(x−1) = −1 − 5/(x−1). Setting f(x) = −1 gives x + 4 = x − 1, i.e. 4 = −1, which is impossible. The remainder −5 is never 0.
  • Special case y = 0 (when n < m): the graph crosses the asymptote exactly at the x-intercepts, since f(x) = 0 only where the numerator is 0.
  • Oblique example: Problem 11's curve meets y = ½x − 2 where the remainder 8x + 4 = 0, i.e. at (−½, −9/4).
  • Limits: solving numerator − y₀·denominator = 0 gives a polynomial of degree at most n, so there are at most n crossings. Also, an x-value that makes the denominator 0 (a vertical asymptote or hole) never counts as a crossing.
  • Vertical asymptotes are different: the function is undefined there, so the graph can never cross one.

PROBLEM 11 — oblique asymptote, no holes

f(x) = (x³ − 2x² + x) / [2(x+1)²] = x(x−1)² / [2(x+1)²]

▶ Show solution

Numerator and denominator share no common factor — (x−1)² and (x+1)² are different — so there are no holes.

Numerator degree (3) is exactly one more than denominator degree (2) → expect an oblique asymptote. Long-dividing x³ − 2x² + x by 2x² + 4x + 2 gives quotient ½x − 2 (remainder discarded for the asymptote).

x-intercepts(0,0), (1,0)
y-intercept(0,0)
Oblique asymptotey = ½x − 2
Vertical asymptotex = −1
HolesNone

PROBLEM 12 — equal degrees, horizontal asymptote

f(x) = (x²+3x−4) / (−x²+2x−1) = (x+4)(x−1) / [−(x−1)²]

▶ Show solution

The denominator has (x−1) squared, but the numerator only has it once. So only one copy cancels: f(x) = (x+4) / [−(x−1)] for x ≠ 1, and a copy of (x−1) is still left in the denominator. Since the factor doesn't disappear completely, x = 1 is a vertical asymptote, not a hole — a hole only happens when a factor cancels out entirely from both top and bottom.

Numerator and denominator both degree 2 (before cancelling) → horizontal asymptote is the ratio of leading coefficients: 1/−1 = −1.

x-intercepts(−4,0)
y-intercept(0,4)
Horizontal asymptotey = −1
Vertical asymptotex = 1
HolesNone

Extra practice — asymptote types & crossings

EXTRA A — classify the end-behavior asymptote

For each, state the horizontal and/or oblique asymptote: (a) (5x − 1)/(x² + 2)   (b) (4x³ + 1)/(2x³ − x)   (c) (x² − 3x + 2)/(x + 1)   (d) x⁴/(x² + 1)

▶ Show solution

(a) n = 1 < m = 2 → HA y = 0.

(b) n = m = 3 → HA y = 4/2 = 2.

(c) n = 2 = m + 1 → no HA, oblique. Synthetic division with c = −1 on 1, −3, 2 gives 1, −4 | 6, so y = x − 4.

(d) n = 4 is 2 more than m = 2 → no HA and no oblique. x⁴/(x²+1) = x² − 1 + 1/(x²+1), so for large |x| it follows the parabola y = x² − 1.

EXTRA B — oblique asymptote with a quadratic denominator

Find the oblique asymptote of f(x) = (x³ + 2x² − x)/(x² + 1).

▶ Show solution

Synthetic division is not allowed (the divisor is not linear), so use long division. x³ ÷ x² = x: subtract x³ + x → 2x² − 2x. Then 2x² ÷ x² = 2: subtract 2x² + 2 → remainder −2x − 2.

f(x) = x + 2 + (−2x − 2)/(x² + 1) → oblique asymptote y = x + 2

Setting the remainder −2x − 2 = 0 shows the graph crosses this asymptote at x = −1.

EXTRA C — does it cross the HA? (equal degrees)

f(x) = (3x² − 2x)/(x² + 1). Find the horizontal asymptote and any point where the graph crosses it.

▶ Show solution

n = m = 2 → HA y = 3. Set f(x) = 3: 3x² − 2x = 3x² + 3 → −2x = 3 → x = −3/2.

Crosses at (−3/2, 3)

Denominator x² + 1 is never 0, so the crossing is valid. Check: f(−3/2) = (27/4 + 3)/(13/4) = 3 ✓.

EXTRA D — HA is y = 0

f(x) = (x − 2)/(x² − 1). Where, if anywhere, does the graph cross its horizontal asymptote?

▶ Show solution

n = 1 < m = 2 → HA y = 0. Setting f(x) = 0 means numerator = 0 → x = 2.

Crosses at (2, 0) — its x-intercept

Vertical asymptotes are x = ±1, which the graph never touches.

EXTRA E — a graph that never crosses

f(x) = (2x + 1)/(x − 3). Does it cross its horizontal asymptote?

▶ Show solution

HA: y = 2. Set (2x + 1)/(x − 3) = 2 → 2x + 1 = 2x − 6 → 1 = −6, which is impossible. Equivalently f(x) = 2 + 7/(x − 3), and the remainder 7 is never 0.

Never crosses y = 2

EXTRA F — crossing an oblique asymptote

f(x) = (x² + x − 2)/(x − 2). Find the oblique asymptote and decide whether the graph crosses it.

▶ Show solution

Synthetic division with c = 2 on 1, 1, −2 gives 1, 3 | 4, so f(x) = x + 3 + 4/(x − 2). Oblique asymptote: y = x + 3.

The remainder term 4/(x − 2) can never equal 0, so:

Never crosses y = x + 3

Compare Problem 11, where the remainder does hit 0, so it crosses.

07

Building a Function from Its Zeros

The method

  • Every given zero c becomes a factor (x − c).
  • An irrational or complex zero never travels alone — its conjugate is automatically also a zero of a polynomial with rational/real coefficients. Multiply the conjugate pair together first: (x−a−b)(x−a+b) = (x−a)² − b² clears the radical or the i.
  • If a point on the graph (not an intercept) is given, or the problem says "fully expanded with integral coefficients," you may need a leading constant a — solve for it using that extra point.
  • Multiplicity shown on a graph (a bounce vs. a crossing) tells you whether a factor needs to be squared.

PROBLEM 10 — irrational conjugate pair

Zero: x = (1 − √3)/2. Find the quadratic (integral coefficients).

▶ Show solution

The conjugate (1+√3)/2 must also be a zero. Multiply the two factors:

f(x) = (x − ½)² − (√3/2)² = x² − x + ¼ − ¾ = x² − x − ½

Not integral yet — multiply the whole thing by 2 to clear the fraction:

f(x) = 2x² − 2x − 1

PROBLEM 13 — complex conjugate pair, cubic

Zeros: x = −3 and x = 2 − 3i.

▶ Show solution

The conjugate 2+3i is also a zero. Multiply that pair first: (x−2)² − (3i)² = (x−2)² + 9 = x² − 4x + 13 (since i² = −1, subtracting a negative adds).

Then multiply by the remaining factor: (x+3)(x² − 4x + 13).

f(x) = x³ − x² + x + 39

PROBLEM 14 — reading multiplicity off a graph, solving for the leading constant

Graph shows a double zero at x = −2 (bounce) and a single zero at x = 1 (crossing), passing through (0, 2).

▶ Show solution

The bounce at x=−2 means that factor is squared: f(x) = a(x+2)²(x−1).

Use the point (0,2): f(0) = a(4)(−1) = −4a = 2, so a = −½.

f(x) = −½(x+2)²(x−1) = −½x³ − (3/2)x² + 2

A missed or wrong leading constant a was the single most common point deduction on this problem — always check your function against the given point before finalizing.

09

Exam-Day Checklist

  • Inequalities: move everything to one side before factoring, and mark denominator zeros as always-excluded.
  • Track whether each factor's exponent is odd (sign flips / graph crosses) or even (sign stays / graph bounces).
  • Synthetic division: use +c for a factor (x−c), and don't forget 0 placeholders for missing terms.
  • Complex and irrational zeros always arrive with their conjugate — multiply that pair first when rebuilding a function.
  • Rational functions: cancel shared factors first — a factor that cancels completely is a hole; a factor left over in the denominator (even after partial cancelling) is a vertical asymptote.
  • Horizontal vs. oblique asymptote comes down to comparing numerator and denominator degree — equal, less, or exactly one more.
  • When a leading constant "a" is needed, plug in the given point last and solve for it — check it against the graph before moving on.
  • Oblique asymptote only when numerator degree = denominator degree + 1 — divide to get the line. Degree 2+ higher means no line at all.
  • Rational Root Theorem candidates are ±(factors of constant)/(factors of leading coefficient); test small ones first.
  • Graphs can cross horizontal/oblique asymptotes but never vertical ones.
  • Plug your final answer back in: test a point for inequalities, check sum/product of zeros, and confirm the given point for a leading constant.
  • To see if a graph crosses its horizontal asymptote, solve f(x) = y₀ — a solution in the domain means yes; no solution means never.
